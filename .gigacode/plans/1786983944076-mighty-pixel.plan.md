# План разработки каталога интернет-магазина (Laravel + Vue 3 + Inertia.js)

## Архитектура

```
┌──────────────────────────────────────────────────────────┐
│  Nginx (port 8400) → Laravel Backend → PostgreSQL       │
│                                                          │
│  Frontend: Vue 3 + Inertia.js (SPA)                      │
│    ├── Layouts/           (app.vue, sidebar)             │
│    ├── Pages/             (Catalog.vue, Product.vue)     │
│    ├── Components/        (ProductCard, Pagination,      │
│    │                       SortSelect, FilterSidebar)    │
│    ├── Composables/       (useProducts, useFilters)      │
│    └── Types/             (TypeScript interfaces)        │
│                                                          │
│  Bootstrap 5 (для компонентов карточек, пагинации)       │
└──────────────────────────────────────────────────────────┘
```

**Layout:** Sidebar слева (группы), основной контент справа (товары + фильтры)

**Файлы для создания:**
- `app/Models/Group.php`
- `app/Models/Product.php`
- `app/Models/Price.php`

**Связи:**
```php
// Group
public function parent() { return $this->belongsTo(Group::class, 'id_parent'); }
public function children() { return $this->hasMany(Group::class, 'id_parent'); }
public function products() { return $this->hasMany(Product::class, 'id_group'); }
public function getAllProductsCount() { recursive COUNT across children }

// Product
public function group() { return $this->belongsTo(Group::class, 'id_group'); }
public function price() { return $this->hasOne(Price::class, 'id_product'); }

// Price
public function product() { return $this->belongsTo(Product::class, 'id_product'); }
```

## Этап 3: Сервисный слой (Service Layer)

**Файлы для создания:**
- `app/Services/CatalogService.php`

**Методы:**
```php
class CatalogService {
    // Группы первого уровня с общим количеством товаров
    public function getTopLevelGroups(): Collection;
    
    // Дерево групп + товары в выбранной группе
    public function getGroupTree(int $groupId): array;
    
    // Товары с пагинацией и сортировкой (оптимизированные запросы)
    public function getProducts(
        ?int $groupId, 
        string $sortBy = 'price', 
        string $sortOrder = 'desc', 
        int $perPage = 12
    ): PaginatedResult;
    
    // Карточка товара
    public function getProduct(int $id): ?Product;
    
    // Хлебные крошки
    public function getBreadcrumbs(int $productId): array;
    
    // Полный breadcrumb для группы
    public function getGroupBreadcrumbs(int $groupId): array;
}
```

**Оптимизации:**
- Eager loading для групп (с каскадным COUNT)
- ONE query для групп + COUNT товаров
- Paginate() для товаров вместо get() + manual slice

## Этап 6: Комposables и логика фильтрации

**useProducts.ts:**
- Реактивные state: products, pagination, loading, error
- Методы: fetchProducts(), nextPage(), prevPage()
- Inertia visit() для AJAX запросов без перезагрузки

**useFilters.ts:**
- Реактивные state: sortBy, sortOrder, perPage, groupId
- Авто-обновление products при изменении фильтров

**UX:**
- Vue transitions для плавного обновления списка
- Loading spinner при AJAX запросах
- Empty state (когда ничего не найдено)
